密钥集合里两个 kid 写成了同一个，验签时挑错了公钥，攻击者用自己的私钥就签过了：指纹必须只由必需字段按固定顺序计算，同一个密钥无论附带哪些可变字段或以什么次序书写，两次计算都必须得到同一个指纹；kid 必须唯一，集合里出现冲突就必须拒绝；验签必须按指纹选择密钥，不能按 kid 猜测，也不能在找不到时退回某把默认密钥；密钥用途必须匹配，签名密钥不能用于加密；已停用的密钥不得参与选择或验签；批量验签时每条消息各自独立选择密钥并各自校验，前一条消息的结果不得影响后一条。不变量是同一密钥两次计算的指纹相同，且 kid 冲突的集合必定被拒绝。

运行与初始状态
在仓库根目录执行 python -m pytest tests -q。初始状态下公开测试五条全部失败，失败必须来自断言，不得出现收集错误、导入错误或语法错误。

验收范围
公开测试覆盖密钥解析、指纹稳定、按指纹选择密钥、kid 冲突拒绝与批量消息独立。隐藏验收不随仓库分发。实现只使用 Python 标准库，不联网，不使用随机数。

补充契约
指纹是 SHA-256 的十六进制字符串。解析后的密钥类型与曲线名大写，用途小写，标识与文本字段去掉首尾空白。停用状态由 disabled 为真、retired 为真、active 为假，或 status 为 disabled、revoked、inactive、retired 表示。
